# timesync — 时间重映射 / 音频重采样分离模型

针对变速播放（0.2×–4× 分段速度曲线）下“逐字字幕保留、但音高与口型
失同步”的问题。根因是把**时间轴重映射**和**音频波形重采样**混为一谈：
直接按曲线抽取源样本会同时改变波形周期（音高漂移）。本模块把两者拆成
独立两层，并对每段曲线做独立审计，禁止用一个全局偏移量修补。

## 模型分层

- `remap`：纯时间轴模型。分段线性速率 `r(s)`，输出时间是其精确积分
  `t(s)=∫1/r(u)du`，支持常数段与线性变速段的解析正/逆映射。
  所有查询只在**包含该时刻的那一段**内计算，不存在全局偏移参数。
- `audio`：只负责“如何把源样本摆到重映射后的帧位置”。
  - `LinearResampler` 逐帧线性插值，忠实跟随曲线但会改变音高，用来复现缺陷。
  - `TSMResampler` 固定合成 hop、分析帧位置由曲线逐帧局部反演得到，
    帧内波形不缩放，Hann 窗 OLA 归一化，输出帧位置仍精确贴合重映射时间轴，
    同时音高保持不变（保口型/音素时序）。
- `subs`：逐字事件走与音频同一条曲线，文本原样保留，逐事件独立映射，
    顺序单调性可校验。
- `audit`：逐段核对源样本数、期望/实际输出样本数、`Map/Inverse` 往返误差、
    局部斜率 `dt/ds=1/r`、音高漂移、字幕独立映射，并做全局偏移拒绝实验。

## 为什么全局偏移不合法

在所有分段边界锚点上拟合最优仿射线 `t=α·s+δ`。若单一常量偏移能修补曲线，
所有锚点应落在该线上；实际分段曲线的最大残差远大于 2 ms 容差（演示数据
约 4.1 s），审计据此拒绝。字幕若被统一平移同样会在“逐事件重新映射”检查中
被抓到（见 `audit/audit_test.go` 的 `TestTamperedSubtitlesCaught`）。

## 运行

```bash
go test ./...
go run ./cmd/timesync
```

演示构造 1×、0.2×、0.5×、2×、4× 与一段 4×→0.5× 线性斜坡，输出每段
审计表、全局偏移拒绝结论、朴素重采样 vs TSM 的音高对比，以及逐字字幕的
源/输出时间戳。审计失败时进程以非零码退出。
