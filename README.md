# subaudit

发行包内嵌字幕（embedded）与外挂字幕（sidecar）一致性审计工具。仅依赖 Go 标准库。

## 配对依据

文件名相同**不**作为通过条件。配对完全基于内容指纹：

1. **语言**：从文件名词尾的 BCP-47/ISO 639 标签或文件头（VTT `Language`、ASS `Language:`）提取，
   `eng` 等三字母代码归一化为 `en`。语言不同的轨道永远不会配对。
2. **内容哈希**：规范化（去标签、去语音标记、合并空白）后的 cue 文本 SHA-256，
   同一翻译在 SRT/VTT/ASS 之间哈希一致。
3. **时间基**：原始刻度（SRT/VTT 毫秒=1000，ASS 厘秒=100）与从时间戳残差推断的帧率网格
   （23.976/24/25/29.97/30/50/59.94/60）。23.976 与 24 视为不同时间基。
4. **cue 数量**：条目数。

另计算**时间轴哈希**（起止时间序列）用于识别仅翻译文本变化的场景。

## 判定

| 判定 | 条件 |
| --- | --- |
| `SAME`（相同） | 语言、内容哈希、时间基、cue 数量（及时间轴）全部一致 |
| `PARTIAL_CHANGE`（部分变化） | 同语言且仍可识别为同一轨道，但翻译、时间基或时间轴中至少一项变化 |
| `MISMATCH`（完全不一致） | 仅语言相同，内容/时间基/cue 数量/时间轴指纹全部对不上 |

语言组在另一侧没有任何对应轨道时列入“未配对”，而不是强行判定。

## 用法

```sh
go build ./cmd/subaudit
subaudit -embedded <内嵌字幕抽取目录> -sidecar <外挂字幕目录>          # 中文可读报告
subaudit -embedded <内嵌目录> -sidecar <外挂目录> -json               # 机器可读 JSON
```

支持 `.srt`、`.vtt`、`.ass`/`.ssa`，递归扫描目录。存在 `MISMATCH` 或未配对条目时退出码为 1，
全部通过为 0，参数/解析致命错误为 2。

## 测试

```sh
go test ./...
```

`testdata/` 下的固件刻意使用互不相同的文件名，覆盖相同、部分变化、完全不一致和未配对四种结果。
