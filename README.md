# 重采样时域取证（纯 Go）

比较同一音乐的原生 44.1 kHz 文件与 48 kHz 转换文件，判断瞬态变宽来自：

- 转换链路的抗混叠/抗镜像滤波、群延迟或边界处理；
- 44.1 kHz 源文件里本来就有的内容展宽、前回声或编码损伤。

工具先估计并报告目标文件相对源文件的样本延迟，再做逐帧复数传递函数、相对脉冲响应、分频段群延迟、瞬态首/尾相位和边界模型比较。

**不使用整段平均频谱相似度作为判据。** 平均频谱相似度会把几十毫秒的时域错位和相位畸变平均掉；本工具的报告里 `AggregateSpectrumUsed` 固定为 `false`。所有相位与误差指标都先按显式延迟对齐。

运行时只使用 Go 标准库，不调用 `ffmpeg`、`sox`、Python 或外部 DSP 库。

## 输入限制

- 输入必须是 RIFF/WAVE。
- 支持 PCM 8/16/24/32-bit、IEEE float 32/64-bit、`WAVE_FORMAT_EXTENSIBLE`。
- 默认对所有声道求平均；立体声反相内容建议用 `-source-channel 0` 和 `-destination-channel 0` 指定单声道。
- 建议两个文件来自同一母带，且目标文件没有被额外做响度、限幅或 EQ 处理，否则归因会混入其它处理。

## 运行

```bash
go run ./cmd/resampleforensics \
  -src original-44100.wav \
  -dst converted-48000.wav
```

输出 JSON：

```bash
go run ./cmd/resampleforensics \
  -src original-44100.wav \
  -dst converted-48000.wav \
  -format json -out report.json
```

常用参数：

```text
-cutoff 20000                 参考重采样的通带边缘；0 自动取较低 Nyquist 的 95%
-reference-half-width 64      参考 sinc 半宽（源样本）；0 用 64
-fft 32768                    Welch FFT 长度；0 用 32768
-min-coherence 0.85           复数传递函数的相干门限
-boundary-window-ms 50        首尾边界比较窗
-max-transients 12            最多报告的瞬态数
-source-channel / -destination-channel
```

## 指标怎么读

### 1. 对齐延迟

先在包络上做强相关，再在最强瞬态附近用原始波形细化，得到 `LagSamples`。正值表示：

```text
destination[i + LagSamples] ≈ reference[i]
```

延迟未解决时，后续瞬态位移、首尾相位和边界误差都不可信。报告会给出相关系数 `Confidence`，弱相关会进入 `Warnings`。

### 2. 群延迟

对每个 Welch 帧计算：

```text
H(f) = Σ conj(R(f)) Y(f) / Σ |R(f)|²
```

`H` 的相位斜率给出群延迟。报告同时列出：

- `relative_group_delay_ms`：整数延迟对齐后的残余群延迟。
- `latency_referenced_group_delay_ms`：整数延迟 + 残余群延迟。
- `ripple_p95_p5_ms`：频段内群延迟波动；线性相位 FIR 通常较平，IIR/最小相位或级联滤波器更容易出现频变延迟。
- `median_coherence`：该频段复数传递函数的可信程度。

不要只看某个频段的绝对延迟。更有诊断价值的是：相位是否线性、群延迟是否随频率倾斜/波动，以及高相干频段是否覆盖到预期带宽。

### 3. 相对脉冲响应

把复数 `H(f)` 去掉拟合线性相位后做 IFFT，得到相对脉冲响应。报告：

- `support_40db_ms` / `support_60db_ms`：相对主峰的连续有效支撑。
- `energy_99pct_ms`：主脉冲附近 99% 能量跨度。
- `pre_energy_db_rel_post`：前置/后置振铃能量比。线性相位 FIR 常接近对称；最小相位/IIR 通常后置能量更大。
- `symmetry`：峰两侧波形的相关系数。
- `linear_phase_likely`：对称性和相干性同时通过时的标志。

滤波器长度无法从成品音频唯一反推。`support_60db_ms` 是“有效”长度；`latency_implied_taps_if_uncompensated` 只在观察到的线性相位延迟没有被转换器内部补偿时才有意义。真正可靠的长度证据来自边界评分中的候选半宽搜索。

### 4. 瞬态宽度、上升时间与首尾相位

在 44.1 kHz 源、合成 48 kHz 参考、实际 48 kHz 目标上分别检测瞬态，使用 1–8 kHz 零相位带通后的解析信号包络：

- 宽度：10% 包络前沿到后沿。
- 上升时间：10%→90% 包络。
- 首移/尾移：目标相对参考的 50% 前沿/后沿时间差，单位 ms。
- 首/尾相位误差：两个解析信号在各自 50% 前沿/后沿处的相位差。
- 前/后能量：峰值前 10 ms 与后 40 ms 的能量比，用于识别原有的前回声/预振铃。

判读顺序：

1. 44.1 kHz 源和合成 48 kHz 参考本就一样宽，目标明显更宽：转换链路增宽。
2. 源和参考都有类似前回声/宽瞬态，目标只增加很小时：原文件内容/既有编码损伤更可疑。
3. 只有文件首尾误差升高、内部瞬态指标接近：边界处理更可疑。

单个瞬态可能是演奏/素材差异，结论使用多个瞬态的中位数和 P90；不足两个有效瞬态时报告为证据不足。

### 5. 边界处理

在首尾各取短窗口，同时搜索：

- `zero`：文件外补零；
- `reflect`：镜像延拓；
- `clamp`：保持首/尾样本；
- 参考滤波器半宽：4–128 源样本中的一组候选。

每个组合使用 2 ms 局部 NRMSE，取最差短窗，避免长窗口把短暂边缘污染平均掉。最佳模型、半宽、与次优模型的余量以及全部候选分数都会输出。若前五名没有同一模型占多数且余量小于 5%，标记为不确定。

这比固定一个很长的参考滤波器更可靠：短转换滤波器在首尾的影响只持续很短时间，用长参考会把它的边界行为稀释。

## 归因规则

工具输出三类主结论：

- `resampler`：目标相对合成参考出现稳定的瞬态宽度或 10–90% 上升时间增加；群延迟/脉冲响应同时给出滤波或相位证据。
- `source_content`：44.1 kHz 源本身已经具有相近的宽瞬态/前回声，目标没有稳定增加；此时不能把问题归给重采样。
- `inconclusive`：有效瞬态不足、相干性过低、对齐不可信，或宽度变化没有超过阈值。

边界模型、群延迟波动、IR 对称性和有效支撑会作为独立证据写入 `Attribution.Evidence`。主结论不会因为没有平均频谱相似度就假装“完全相同”；无法判定的指标显示 `n/a`。

## JSON 主要字段

```text
alignment.lag_samples                       目标相对源的样本延迟
group_delay.bands[]                         分频段相对/总群延迟、波动、相位 RMS、相干性
group_delay.effective_bandwidth_3db_hz      复数传递函数的有效 3 dB 带宽
impulse_response.support_60db_ms            相对 IR 的 -60 dB 有效支撑
impulse_response.symmetry                   线性相位/最小相位线索
transients.events[]                         每次瞬态的三路宽度、上升时间、首尾位移/相位
boundary.scores[]                           boundary mode + 参考半宽的完整候选分数
attribution.classification / confidence     归因与置信度
```

## 方法概要

1. 用 Blackman 窗 sinc 有理数重采样，从 44.1 kHz 源生成 48 kHz 参考。默认参考半宽 64 源样本，远长于常见短 FIR，目标是近似理想带限插值。
2. 包络相关给出粗延迟，最强瞬态附近原始波形相关给出细化延迟。
3. 以 50% 重叠 Hann 帧计算复数互谱 `H` 和 magnitude-squared coherence，只在高相干、高能量频点估计相位与群延迟。
4. 从 `H` 反变换得到相对 IR；用自适应噪声底约束 -40/-60 dB 有效支撑，报告前置/后置能量与峰对称性。
5. 在源、参考、目标三个时间序列上分别测量瞬态；源文件作为内容基线，避免把原本就存在的展宽算到转换器头上。
6. 对首尾分别用 zero/reflect/clamp 及多个滤波器半宽生成短参考片段，按 2 ms 局部 NRMSE 选最佳组合。

## 限制

- 无法从成品 48 kHz 文件唯一恢复转换器的具体实现、tap 数或内部工作采样率；报告的是可观测的有效响应。
- 如果 44.1 kHz 源在进入本工具前已被有损编码、限幅或其它处理污染，工具能显示“源里已有”，但不能修复或追溯原始母带。
- 分析通带默认截至约 20.95 kHz（44.1 kHz 的 95% Nyquist）；超过该范围的相位不参与结论。
- 极短文件、静音、单声道反相下混或只有一个瞬态时，统计稳定性和相位可靠性会下降，报告会明确标注。
- WAV 解码不包含 DRM、压缩格式或损坏文件修复。

测试覆盖：

- FFT 往返、相位展开；
- 44.1→48 kHz 正弦重建误差；
- 延迟对齐与 latency-referenced 群延迟；
- 合成瞬态上的宽度/上升时间归因；

- WAV 16/24-bit 解码与非法输入。
